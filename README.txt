LUDO FRIENDS — VERCEL SEM CONFIGURAÇÃO

IMPORTANTE:
1. Apague TODOS os arquivos antigos do repositório/pasta do jogo.
2. Deixe somente index.html e vercel.json desta pasta.
3. Envie para o GitHub.
4. A Vercel fará um deploy estático, sem Node, Redis, API, banco ou variáveis.

Arquivos antigos que NÃO devem ficar no projeto:
- package.json
- package-lock.json
- server.js
- pasta api/
- pastas public/ ou src/ de versões anteriores, se forem só do Ludo antigo

O index.html contém HTML, CSS e JavaScript do jogo no mesmo arquivo.
