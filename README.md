# Ludo Friends

Versão estática para Vercel/GitHub Pages.

## Modos
- Jogar com amigo por link
- Jogar contra o robô
- 2 jogadores no mesmo celular

## Publicação
Envie os arquivos desta pasta para a raiz do projeto e faça o deploy.
Não precisa Redis, banco, Node ou variáveis de ambiente.

O modo online usa PeerJS para sinalização e OpenRelay TURN como fallback para redes diferentes.
