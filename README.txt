ADONES CELL - PROTÓTIPO

Arquivos principais:
- index.html: site público
- painel.html: painel administrativo
- styles.css: visual completo
- app.js: simulador e consulta da OS
- painel.js: ordens, financeiro e gastos

COMO TESTAR:
1. Abra index.html no navegador.
2. Clique em "Painel" no topo para acessar o painel administrativo.
3. Cadastre ou edite ordens de serviço.
4. Os dados ficam salvos no localStorage do próprio navegador.
5. Use o número da OS no site público para consultar o status.

Este é um protótipo front-end e não utiliza banco de dados.
