# Ludo Friends - modo Robô

Versão estática e simples para Vercel.

## Arquivos
- index.html
- styles.css
- game.js
- vercel.json

## Como publicar
Apague os arquivos antigos do projeto do Ludo e envie estes arquivos para a raiz do repositório.
Não precisa Redis, banco, Node, API ou variável de ambiente.

## Modos incluídos
- Jogar contra o Robô (100% local/offline)
- 2 jogadores no mesmo celular

O modo online foi removido desta versão para não interferir no jogo enquanto a conexão multiplayer é corrigida separadamente.
